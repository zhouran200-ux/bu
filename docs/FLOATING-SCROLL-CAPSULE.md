# 浮动空心滚动胶囊

按用户相册截图右边缘框选样式：独立竖向空心胶囊，22×46dp、2dp描边、右侧3dp间距，无背景填充、不画轨道、不按文字长度伸缩。颜色跟随当前文字色，浅背景深线、深背景浅线。

默认隐藏，仅列表滚动或正在拖胶囊时出现；停止650ms后淡出140ms。隐藏完成后胶囊组件不在布局中，无触摸或无障碍焦点；全高外层仅定位，不注册pointerInput。只在浮动胶囊28×52dp局部区域挂手势。

对话和来源文档页复用FloatingScrollCapsule，文档活跃页才启用。对话键盘开启时不显示；历史入口仍只在输入栏。长消息定位复用按key测量/冻结快照逻辑，不复活旧平均高度轨道。因胶囊本身会移动，用localToRoot获取全局手指坐标，避免局部坐标因跟随手指移动造成抖动。

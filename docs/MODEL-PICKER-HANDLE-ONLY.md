# 模型抽屉交互与简约布局

## 范围
获取模型多选抽屉与对话方案/模型抽屉。复用Material ModalBottomSheet显示和hide动画，不新增Dialog或导航页。

## 手势
两处sheetGesturesEnabled=false，列表滚动不驱动抽屉。共用ModelPickerDrawer：仅居中横杠72×40dp区域挂垂直draggable；下拉使抽屉内容整体移动，向上不能收起；距离达到56dp或有位移且下拉速度达1000px/s触发hide，动画结束后移除。短拖动回弹，手势开始取消回弹任务，关闭时拒绝重复请求。遮罩点击和系统返回保留Material默认行为；“仅横杠收起”限定滑动手势，不更改返回键。

获取模型：勾选仅改draft，确认在hide结束后提交选择并关闭。下拉放弃未确认draft。对话模型：点模型更新选择，不自动关闭；通过横杠下拉、返回或遮罩关闭。管理API入口继续使用原有设置页面和返回恢复逻辑。

## 视觉
方案标题14sp、最小40dp，箭头+数量表达可展开层级，不在折叠方案头重复模型名；方案间细线与轻留白，分割线放在方案标题item内部，避免改变初始列表定位公式。模型缩进24dp，13sp、最小36dp，最多两行；移除对号，当前模型采用正文色12%透明度背景，亮/暗/纯白随主题文字色适配。入口只显示方案名，没有选择时显示选择方案。获取多选保留Checkbox以明确多选语义。

# 模型弹窗展开、定位和关闭修正

- 所有非空方案（包含只有一个模型的方案）点击标题只展开/折叠，不调用 onSelect。点击具体模型行才提交选择。
- 每次创建弹窗以当前方案 ID 和模型计算展开状态、列表初始索引，只有选中方案默认展开；索引由前面的折叠方案标题数量、标题行和当前模型在统一候选列表中的位置计算，不写死方案、模型名称或下标。选择/排序导致定位结果变化时重新初始化；普通手动展开不会不断被效果重置。
- LazyListState 使用初始索引直接定位到选中模型，不延时从顶部滚动。不存在方案或空候选安全回退。
- 旧逻辑禁用 sheetGesturesEnabled，自定义 LucentDragHandle 只移动把手并直接销毁弹窗。此弹窗改用 Material 底部弹窗原生把手、拖动与嵌套滚动，弹窗本体跟随手势。
- 点击模型或 API 管理入口先执行 sheetState.hide，动画结束再回调选择/导航和关闭；关闭中禁止重复点击。系统返回/遮罩/拖动完成采用 ModalBottomSheet 原生 dismiss 回调。

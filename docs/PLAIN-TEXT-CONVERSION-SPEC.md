## 二、转换规则

### R1 章标题
- 匹配：行首 `第` + 中文/全角数字 + `章|回|节|卷|部|篇`。
- 章后**允许无分隔符**：`第一百零八章小发现` 也是标题。
- 反例约束：章标记之后的内容若**超过 30 字**或**含句末标点**，则不视为标题（排除 `第二天上班。因为…`、`第一条腿放上去…`）。
- 输出：`# 章标题`（原标题文字，行首行尾空白去掉）。

### R2 场景分隔符
- 匹配：整行仅由 `…`、`.`、`·`、`*`、`-`、`_`、`—` 等分隔类符号组成，且长度 ≥ 2。
- 输出：`---`（Markdown 分隔线），与前后段之间隔空行。
- 这解决了原文 24 处 `……` 被当成普通段落的问题。

### R3 段落切分
- **空行**：一定是段落边界。
- **章标题、分隔符**：前后一定是段落边界。
- **硬换行续接**：若上一行**未以句末标点结尾**，则当前行接续同一段。
  - 句末标点集合：`。！？…"』」】）.!?`
  - 续接时中文与中文之间**不加空格**，其余情况**加一个空格**（避免英文单词粘连）。
- **列表项**：编号列表行（`1.` `2.` `1、` `1)`）各自成段，且不与上一行续接。
- 其余行：各自成段。

### R4 空白与杂项
- 行首行尾空白去掉；连续空行折叠为单个段落边界。
- UTF-8 BOM 去掉。
- 已存在的 Markdown 标题行原样保留。

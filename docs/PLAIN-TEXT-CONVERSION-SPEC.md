# 纯文本 → Markdown 转换规范

来源：根据用户提供的示例小说归纳。**该小说内容不进入仓库、不进入 APK** —— 本文档与全部测试一律使用中性占位文本，主源码中也已不再保留任何原文片段。

## 一、章节标题格式（参考中文网文常见写法）

识别规则：行首允许一个开括号，随后是「数字 + 单位」；数字可用半角、全角或中文数字；`第` 可省略（省略时单位后必须是分隔符或行尾）；单位支持 章/回/节/卷/部/篇/集/话/幕；另支持无编号的常见标记与英文写法。

| 形态 | 示例 |
| --- | --- |
| 中文数字 + 第 | `第一章 标题`、`第一百零八章 标题` |
| 字间空格 | `第 一 章 标题` |
| 阿拉伯数字 | `第1章 标题`、`第108章 标题` |
| 补零 | `第001章 标题`、`第0001章 标题` |
| 全角数字 | `第１章 标题`、`第１００章 标题` |
| 省略「第」 | `01章 标题`、`1章 标题` |
| 无分隔符 | `第108章无分隔` |
| 其他单位 | `第12回`、`第3节`、`第2卷`、`第4篇`、`第5集`、`第6话`、`第7幕` |
| 分隔符 | `第10章：标题`、`第11章、标题`、`第12章-标题` |
| 方括号 | `【第9章】 标题`、`【第9章 标题】` |
| 无编号标记 | `序章`、`序幕`、`序言`、`楔子`、`引子`、`前言`、`后记`、`尾声`、`终章`、`大结局`、`完结章`、`番外`、`番外篇`、`外传`、`附录` |
| 英文 | `Chapter 12`、`Part 3`、`Volume 2`、`Episode 5`、`Section 4` |

排除条件（避免把正文当标题）：标记之后的内容超过 30 字，或含句末标点（`。！？!?`），则不算标题。因此下列正文不会被误判：

- `第二天上班。因为出差，车停在公司了。`
- `第58章的内容仍未结束。`
- `12章鱼很好吃。`
- `楔子是他写的。`

## 二、段落切分

- **空行**、**章标题**、**分隔符**都是段落边界。
- **硬换行续接**：上一行未以句末标点（`。！？…”』」】）.!?`）结尾时，当前行接续同一段；中文相接不加空格，拉丁文之间补一个空格。
- **编号列表**（`1.` `2.` `1、` `1)`）各自成段，且不与上一行续接。
- 其余行各自成段。

## 三、场景分隔符

整行仅由 `…`、`.`、`·`、`—`、`*`、`-`、`_`、`=` 等分隔类符号组成且长度 ≥ 2（如 `……`、`......`、`——`）→ 输出 Markdown 分隔线 `---`。句中的省略号（如 `他走了……然后回头。`）不受影响。

## 四、台词与标题的样式

- **台词**：被引号（`“”` 或 ASCII `"`）包裹的片段输出为 `“*台词*”` —— 引号保留，仅内容斜体；叙述部分保持正体。不要求引号严格配对，未配对时原样保留。
- **章节标题**：输出 `# 标题`，单独一行，与前后段之间空一行；渲染时按标题层级加粗（`FontWeight.Bold`），并上下各留 10dp 间距。

## 五、空白与杂项

段首尾空白去掉（全角空格也去掉）、连续空行折叠、UTF-8 BOM 去掉、整行被方括号包裹时去掉外层括号。

## 六、验收

- `DocumentSectionTest`：28 种章节形态 + 6 类反例 + 分章/分块/长章标题保持。
- `PlainTextMarkdownTest`：章节、续接、列表、分隔符、台词、空白与 BOM。
- `SampleNovelConversionTest`：用中性合成文本做端到端转换断言（标题、续接、分隔线、列表、台词样式）。

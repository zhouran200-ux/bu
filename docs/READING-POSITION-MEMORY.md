# 对话与来源阅读位置记忆

## 行为与实现

- 对话按笔记本隔离，来源按笔记本及文档 ID 隔离，保存在独立 SharedPreferences 中，正常退出应用后保留。
- 保存首个可见消息／文档块的稳定 key、列表索引及块内像素偏移；相同文字布局下保留到同一行以及行内的像素位置，不按章节或滚动百分比粗略定位。
- 读取记录后直接构造 LazyListState(initialIndex, initialOffset)。恢复路径不调用 scrollToItem/animateScrollToItem，不先显示顶部再跳转。
- 对话冷启动等待数据库消息加载完成才创建列表，避免空列表把保存的索引归零。加载期间只显示读取提示，不显示错误的对话位置。
- 关闭恢复时默认流式自动跟随；离开对话标签或切设置时暂停跟随，防止隐藏页面被自动拉到底部。主动发送、点击跳到底部和用户滚到底部仍可跟随新回复。
- 思考区的展开状态与内部滚动偏移一并记忆，避免返回时折叠改变消息高度。恢复后的键盘状态不会触发首次自动滚动。
- 使用 snapshotFlow 保存有效布局的位置，并在退出组合树时补存最后一次偏移。列表必须实际完成布局才允许保存，避免未布局的默认值覆盖记录。
- 删除笔记本后清理其对话、思考区及来源阅读记录。缺失／删除锚点时安全回退到最近有效条目，丢弃不再匹配的旧块内偏移。

## 边界

“同一行”以相同窗口宽度、字体大小和文档内容为前提。改变排版参数、编辑文档或删除锚点后，换行和像素高度发生变化，不宣称旧视觉行仍能完全重现。强制终止进程发生在异步偏好写盘之前时，也不能保证保存最后一帧。

- 公共笔记本列表的 rememberRestoredListState 仍有现有用途，未误删。对话手动滚动、历史定位和发送后的滚动保留。
- 生成会话与网络生命周期未改变；位置跟随只影响 UI，不取消后台回复。

- 新增 ReadingPositionTest 覆盖像素偏移往返、消息锚点移动、来源块内位置、删除回退、损坏数据及后台追加不移动锚点。

# 单文档短标签溯源协议 v2

基线6181b38。本轮替换旧600/900硬分段、长REF输出要求、1200阅读块估算定位与2.6秒背景高亮。

## 当前实现
- 每笔记本一文档：加载完成才挂载页面，导入事务检查本存在且无NOTE；重复导入拒绝，不生成孤立Note。导入成功后后台预构建NovelSourceIndex，发送与阅读复用。
- 500为软目标，完整自然段和不跨章为硬约束。跨500时取更近段落边界，等距取前；超长自然段/代码围栏不拆。保留原body范围、CRLF与段内空白；章节单元按标题识别顺序编号，CH仅辅助。
- 新输出〔S：1-1〕，解析兼容半角冒号和旧无冒号；内部id仍S1-1。模型不复制noteId/长摘要。
- NovelPromptBuilder为固定规则→带标全文→自定义设定，本轮最后user消息附reply_contract。原著事实/复述/原文台词与背景必须有依据标签，纯分支不标Canon；引用规则不保证所有服务商遵循。
- ChatSession先后台准备不可变来源与提示词，首次保存及流chunk/final都保留sourceNoteId/sourceRevision。Room32和31→32迁移新增nullable字段，旧记录null不猜当前身份。
- Markdown短标按该回答保存的身份解析，转上标[n]；代码内标签不转也不占号，常规粗体/斜体包含引用不再被截坏。复杂CommonMark并未完整实现。
- 点击后台查缓存验证版本/切片，再切来源页。来源直接slice:item一对一显示，不再搜索原文。目标整片正文加粗，保留italic/代码/列表结构；无色块、无预览弹窗、不写**到正文。粗体持续到另一引用或离开笔记本。
- 短距离动画、远距离直跳，系统关动画直接定位；先应用粗体等待帧再定位。请求消费防切tab重放旧位置，requestId支持重复点击同引用。
- 缓存按文档内容/标题版本失效，最多4来源且总正文预算约200万UTF16字符（单份超预算仍允许），删除evict；不是持久化多版本全文仓库。

## 兼容边界
旧REF仍可显示但旧v1版本不能对新v2坐标猜位置；旧未绑定身份短标不能跳。历史正文与统计不改。新切片规则改变索引版本，旧阅读block位置不套用新slice位置。当前没有新增编辑/替换文档入口。人工预标全文去重/校验尚未实现，不能自动承诺任意外来CH/S标签复用。

## 清理审计
全局追SourceTagging/SourceCitations/Markdown/ChatSession/ChatSessions/Entities/schema32/SourceFocus/reader/prompt/统计字段。删除SourceLocator与专属tests、ChatScrollMath旧文档网格/估算搜索和对应旧测试（保留滚动target/追底公共数学）。替换高亮/2600ms路径；旧REF仅解析兼容/测试存在，新提示词无输出要求。旧schema与迁移保留，无新依赖/权限/通知/后台服务。测试改为完整段/准确substring/短标版本/整片强调。

## 验证
全量JVM测试、Release Kotlin及AndroidTest Kotlin编译通过；44项Python工具/契约通过；129文件卫生、嵌套滚动检查通过。新增31→32迁移和单文档重复/已删除本导入设备测试仅编译，不称执行通过。未本地打包APK，未真实LLM验证引用遵循率、未真机验收脚注点击/切页/字重后定位。
